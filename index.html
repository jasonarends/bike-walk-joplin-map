How This Map Works

01

Official JATSO Data

This map loads live data from the JATSO Bike & Pedestrian Plan — a formal effort with contractor Crafton Tull. Those points and routes appear in purple.

02

Draw on the Map

Use "Add to Map" to place a pin, draw a multi-segment route, or outline a problem area. Then add context — type, description, photos.

03

BWJ Advocacy

Bike Walk Joplin uses community submissions to advocate with city officials and build the case for a safer, more connected Joplin.

04

Open Data

All community submissions are stored in a public database that JATSO, the city, and other partners can query — just like the ArcGIS data.
